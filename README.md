# Control de gastos

Aplicación web orientada al registro y seguimiento de finanzas personales, permitiendo llevar un balance claro de ingresos y egresos.

## Funcionalidades
- Registro de movimientos con descripción y monto.
- Cálculo automático del balance general, ingresos totales y gastos acumulados.
- Eliminación de registros individuales.
- Almacenamiento local para conservar el historial entre sesiones.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Ejecución local
1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en cualquier navegador.
